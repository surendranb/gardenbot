System Schematics

Gardenbot operates as a closed-loop autonomous warden. Environmental telemetry is gathered via the ESP8266 sensory array (BME680, LDR, Soil Probes) and combined with optical and acoustic captures from the host machine. The OpenClaw agent digests this context every 4 hours to evaluate plant vitality and issue care directives.
