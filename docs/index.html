System Architecture
Thermostat-pattern botanical agent design

Thermostat-Pattern Philosophy

Instead of running fragile multi-step bash processes that generate intermediary files, GardenBot v2 uses the proven **thermostat architecture**. The system is completely centered around a single database which acts as the absolute source of truth.

  • Dumb Collectors: collect.py runs periodically via launchd, capturing environmental data (soil moisture, temperature, humidity) and writing directly to SQLite.
  • Asynchronous Eye: vision.py evaluates camera feeds via Gemini Vision and updates the database independently.
  • Decoupled Reasoning: The Warden Agent wakes up every 4 hours, queries historical data from the SQLite DB, applies biological logic via garden_math.py, posts alerts to Slack, and records its interpretation back to the DB.
  • Static Compilation: The dashboard is entirely static, reading data and updates from a compiled JSON file derived straight from SQLite.

About GardenBot

चेन्नई डेस्क बायोम — Chennai Desk Biome

GardenBot is an intelligent, low-intervention botanical companion designed specifically to monitor and manage a single Jade Succulent (Crassula ovata). The plant is housed in a self-watering terracotta pot placed on a physical wooden workstation desk in Chennai, India.

Target Plant Profile

Jades are highly resilient succulents native to southern Africa. They thrive in a soak-and-dry watering regime. Because their roots rot quickly in standing water, the self-watering system relies on a slow-wicking moisture sponge that dries out completely between cycles.

Diagnostic Rules

The system evaluates water requirements based on two signals: Soil moisture index (the physical resistance measured via the capacitive soil probe) and Turgidity (the visual plumpness/thickness of the leaves analyzed by vision). If the soil index is dry but the vision model confirms leaves are thick and turgid, the agent defaults to Hold Water to prevent root suffocation.
